# DAWEki is a single-file, browser-based digital audio workstation built with **Vanilla JS** and **Tone.js**, housed in a single HTML container.

## Key Features

- **Engine & Architecture:** Built using pure Vanilla JavaScript and Tone.js inside a single HTML container.
- **Interface:** Multiple resizable GUI layouts for flexible workflow customization.
- **Multi-Track Recording:** 4-track audio recording with automatic audio interface / sound card detection.
- **Track Effects:** Dedicated EQ, Compressor, Saturator, and Stereo Widener per track.
- **Bus Effects:** Dedicated Bus Reverb and Bus Delay send/return routing.
- **Editing Tools:** Audio region splitting, matrix input/output selection, region gain adjustment, and fade in / fade out handles.
- **Workflow & Export:** Bounce in place functionality, complete project save/load, and direct drag-and-drop file browser support.

## Getting Started

Since DAWEki is fully self-contained in a single HTML file:
1. Download or clone the repository.
2. Open `index.html` in any modern web browser.
3. Grant microphone/audio input permissions when prompted for recording.
